# NO GAME NO LIFE

轻量、本地优先的全天时间记录、成长积累、阶段计划与图文闪回应用。

本仓库保存选定网页版本 **0.3.0-rc3** 的静态发布资源。

## 数据与平台

时间记录、日记、照片与计划保存在访问者自己的浏览器中。公开仓库只包含网页程序，不包含个人使用数据、内部设计资料或安卓签名文件。不同网址及安卓应用的本地存储相互独立，需要使用应用内完整备份导出、导入来迁移。

网页版提供手动计时、活动切换、统计、阶段与成长展示、图文闪回、本地备份。安卓专有的其他 App 使用检测和系统常驻通知不由普通网页提供。

## 发布

采用 GitHub Pages，发布目录为 docs/。Settings → Pages → Source 选择 GitHub Actions 后，在 Actions → Publish selected web release → Run workflow 手动发布。

仅在维护者明确选择版本时才同步仓库和发布；应用每次开发迭代不会自动更新此仓库或任何公开网站。工作流没有 push、PR 或定时触发器。

发布前运行 node scripts/verify-release.mjs。检查通过后再手动发布，记录该次提交及公开访问结果。此检查仅证明静态资源对应选定版本，不代替手机、长期后台或全天体验验证。

## 本地预览

使用任意静态 HTTP 服务提供 docs/，通过浏览器访问。ES 模块与离线缓存需要 HTTP(S)，不要直接双击 HTML 文件。
