# NO GAME NO LIFE

对日常生活进行整理、记录与回看。本仓库保存选定网页版本 **0.9.0-rc2** 的静态发布资源。

网页入口：https://shikou-kb.github.io/no-game-no-life/

## 使用与数据

六个入口为记录、成长、阶段、闪回、迭代、个人。支持手动计时与分类标签、时间概览、培养与阶段关联、图文闪回与碎念、迭代记录和比较、个人外观设置、本地完整备份。数据保存在访问者自己的浏览器中；本仓库不包含个人使用数据、私人参考截图、内部设计稿或安卓签名。

更新前建议从「个人」导出完整备份。浏览器、不同网址及安卓应用的数据各自独立；在同一个网址升级不代表已经云端同步。换浏览器或设备时，使用应用内的完整备份导入。浏览器清理站点数据会移除本地记录。

网页不能读取其他 App 使用情况，也不提供安卓原生的浮球、持续后台服务及系统锁屏计时通知。这些能力只在对应安卓版本中实现，并受设备权限和系统行为影响。

## 发布方式

仅在维护者选定版本时更新仓库并发布。应用的每次开发迭代不会自动更新网站。

发布目录为 `docs/`。运行 `node scripts/verify-release.mjs` 校验选定资源，然后在 GitHub Actions 的 `Publish selected web release` 中手动 `Run workflow`。工作流仅有 `workflow_dispatch`，没有 push、PR 或定时触发。发布后应核对公开入口、静态资源及同源数据读回。

发布前后的资源身份记录在 `release.json`。静态文件校验不能代替真实交互、安卓真机或长期使用验证。

## 本地预览

通过静态 HTTP 服务提供 `docs/`，再用浏览器打开。ES 模块和离线缓存需要 HTTP(S)，不能直接双击 HTML。使用项目子路径 `/no-game-no-life/` 时也应测试资源加载和工作器作用范围。

字体许可与可公开素材来源见 `docs/assets/fonts/` 和 `docs/assets/art/art-sources.json`。
